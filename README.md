# Online Banking Application – Frontend and Backend 

Hey, I am **Priya Kushwaha**, and welcome to my repository! 👋

Welcome to my **Online Banking Full Stack Project – Frontend and Backend**. This project is a web application designed to provide users with a simple, interactive, and user-friendly online banking experience.

The application connects with a Java Spring Boot REST API backend to support banking operations such as user authentication, account management, fund transfers, deposits, withdrawals, and payments.

This project helped me explore frontend development using React and Redux, Backend using Spring Boot, API integration, state management, and communication between frontend and backend applications.

## 📌 About the Project

The Online Banking Application is a **Single Page Application (SPA)** built using React and Redux. Redux is used to manage application state and keep the UI synchronized across components.

The frontend communicates with the backend REST API to retrieve and update banking information, allowing users to perform different banking operations through an interactive interface.

## ✨ Features

- **User Authentication:** Register and log in to the application.
- **Account Management:** View existing accounts and open new accounts.
- **Transaction History:** View account activity and transaction details.
- **Fund Transfers:** Transfer money between accounts.
- **Deposits and Withdrawals:** Perform basic banking transactions.
- **Payments:** Make payments through the application.
- **Dynamic Charts:** View account activity and financial flows through charts.
- **Global State Management:** Manage application state using Redux.
- **API Integration:** Communicate with the Java Spring Boot backend.
- **Responsive UI Components:** Build the interface using Material UI.
- **Single Page Application:** Navigate between application pages without full-page reloads.

## 🔗 Backend Integration

This frontend is designed to work with the Java Spring Boot Online Banking REST API.


The backend provides the APIs required for authentication, account management, and banking transactions.

Make sure the backend is configured and running correctly before testing features that require API communication. Depending on the backend configuration, you may also need to configure the API base URL, CORS settings, and authentication cookies.

## 🚀 Getting Started

Follow these steps to run the frontend locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git
- A running and configured backend API

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

Replace `<your-repository-url>` with the URL of your GitHub repository.

### 2. Navigate to the Project Folder

```bash
cd <your-project-folder>
```

Replace `<your-project-folder>` with the actual frontend directory name.

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Application

```bash
npm run start
```

If the project uses a different start script, check the `scripts` section in `package.json` and use the appropriate command.

### 5. Open the Application

Open the local URL displayed in your terminal after the development server starts.
